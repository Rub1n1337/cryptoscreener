# Учебные материалы на сайте (план, 11.11.2026)

Владелец 11.11: добавить на сайт обучающие материалы и теорию. Этот файл — план и передача дел: сессия, которая делает волну,
читает его первым и отмечает статус в конце.

## Зачем и для кого

- **Для кого:** новичок, который пришёл посмотреть сканер и ботов, и человек, который уже «торгует по курсам» и хочет понять,
  работает ли то, чему его учили.
- **Чем мы отличаемся от курсов:** у нас есть честные проверки на истории — комиссии, честный топ со снятыми монетами,
  заглядывание вперёд, случайный вход, отложенный период. И есть их результаты: популярные идеи проиграли. Почти никто этого
  не показывает. Поэтому учёба строится не вокруг «как зарабатывать», а вокруг **«как устроен рынок и как проверить идею, не
  обманывая себя»**.
- **Каждый урок заканчивается действием на сайте:** открыть стакан, включить индикатор, запустить учебную стратегию в бэктесте.
  Теория без кнопки — только там, где действия нет.

## Принципы (обязательны для всех волн)

1. **Ни слова о том, что даст прибыль.** Ни обещаний дохода, ни «лучшей стратегии», ни советов, что купить. Сервис учебный, это
   уже сказано в подвале («Учебный сервис · не финансовый совет») и в `#legal`; в разделе — та же строка в шапке.
2. **Каждое утверждение — с источником.** О том, что делает сайт, — из кода (`файл:функция`); о результатах проверок — из отчёта
   (`docs/RESEARCH-*.md`, `docs/AUDIT-FABLE-C.md`) с датой. В тексте урока источник для читателя не нужен, но в исходнике урока
   (`learn.js`) у каждой цифры — комментарий с источником. Правило `CLAUDE.md`: перед текстом открыть код и отчёт заново.
3. **Цифры исследований — с датой и условиями** («на часовых свечах за три года до ноября 2026, топ-50»), потому что они
   устаревают. Числа, которые меняются при каждом прогоне, в текст не зашивать (`LESSONS.md`, пункт 10 чеклиста): либо из
   отчёта с датой, либо «запустите и посмотрите».
4. **Язык — простой.** Короткие абзацы, термин объясняется при первом появлении, у каждого термина — ссылка в словарь.
   Без жаргона там, где есть русское слово; английский термин — в скобках один раз (спред, spread).
5. **Не копировать чужие курсы и тексты.** Только своё изложение; формулы и общеизвестные определения — можно.
6. **Дизайн — по `docs/DESIGN-RULES.md`**, цвета только токенами; проверка раздела 12 перед каждым пушем.

## Устройство раздела (вариант А)

- **Адрес:** `#learn` — список модулей; `#learn/<модуль>/<урок>` — урок (например `#learn/test/survivor`). `PAGES` в
  `index.html` получает `learn`; `go()` и `readHash()` — как у других страниц; «Назад» браузера — между уроками.
- **Тексты уроков — в `learn.js`**, загружается при первом открытии раздела (как `changelog.js` через `loadOldChangelog`):
  первая загрузка сайта не тяжелеет. Формат — массив модулей `{id, title, lead, lessons:[{id, title, min, body, try, check}]}`,
  `body` — HTML из разрешённого набора (абзацы, списки, `<b>`, `<dfn data-term>`, картинки-схемы SVG), без `innerHTML`
  из сети: файл свой, со своего домена.
- **Страница урока:** заголовок, «≈ N мин», текст, блок «Проверьте сами» (кнопки действий), «Проверьте себя» (2–3 вопроса,
  необязательно), «Дальше: …». Слева на компьютере — оглавление модуля; на телефоне — список сверху, свёрнутый.
- **Действия («Проверьте сами»)** — кнопки, которые ведут в сайт с заполненными настройками:
  - `#market/BTC` + режим «Стакан» + включить индикатор (`sr_bind` не трогать — включить только на этот показ? → решение
    владельца, по умолчанию: включить и сказать об этом тостом «Включён индикатор VWAP — убрать: ×»);
  - бэктест с готовыми настройками: функция вроде `btFromProf` (`index.html`), заполняет форму и запускает; монеты, период,
    стратегия (`M.STRATEGIES`, `M.STUDY`), риск. Форма бэктеста меняется — урок не должен портить сохранённые настройки
    пользователя (форма после F5 сейчас и так сбрасывается, `AUDIT-FABLE-D.md`, предложение 1);
  - «показать на графике» — открыть монету и таймфрейм.
- **Прогресс:** `sr_learn` = `{done: {урок: дата}, last: урок}` — ключ `profile` в `KEYS` (синхронизируется с профилем при
  входе). Отметка «пройдено» — кнопкой в конце урока, не автоматически при открытии.
- **Словарь:** сейчас `<details class="dis">` «Словарь терминов» в `#help` (`index.html` ≈ стр. 1690). Переезжает в `learn.js`
  (общий источник), справка показывает его так же, как сейчас; в уроках термин `<dfn data-term="spread">` — подсказка при
  наведении / нажатии и ссылка «в словарь». Термины сканера (сила, T½, ширина…) остаются и в справке.
- **Поиск** по урокам и словарю — в быстром поиске (`cmd`, Ctrl+K), если он умеет внешние источники; иначе — во вторую очередь.

### Карта тем → наши проверки

Одна идея под пятью именами: **ложный пробой** (классический теханализ) = **девиация** (торговля в боковике) = **снятие
ликвидности, sweep** (ICT) = **аптраст / спринг** (Вайкофф) = **провал аукциона** (рыночный профиль). Урок о ней нужен первым.

| Тема | Наш прогон |
|---|---|
| Свинги и структура (HH/HL, слом) | прямо — нет; «только по тренду» (20.10) — мало сделок |
| Уровни, ликвидность за ними (PDH/PDL, равные вершины) | нет |
| Пробой / отбой / ложный пробой | отскок от границы канала — минус (`AUDIT-FABLE-C.md`); ложный пробой как правило — **не проверяли** |
| ATR и запас хода | нет; стоп ботов = 1.5 ATR (`math.js`) |
| Объём: VSA, дельта | нет |
| Аукцион, зона стоимости, POC, типы дня, баланс / тренд | нет |
| FVG, ордер-блок, Фибоначчи / OTE | **минус** (07.11, 29.10) — уже в модуле 3 |
| Сессии и киллзоны | нет |
| 1 % риска, плечо не меняет риск | урок «Размер позиции» уже есть |
| RR ↔ винрейт, безубыточность | считается на месте (с нашими издержками) |
| Дневной лимит потерь 2 / 6 | **не лучше случайного пропуска** (13.11, `RESEARCH-LOSS-LIMIT.md`) |
| План, журнал, тильт | журнал на сайте есть |

### Что предлагаю сделать

Пишем «как это объясняют» своими словами со своими схемами и честно говорим, проверяли ли мы это. Где не проверяли — так и пишем:
