# Sigma Radar — состояние разборов

Один короткий файл вместо истории прошлых раундов. Прикладывается к каждому новому разбору (код, стратегия, дизайн) и обновляется после каждой версии. Всё из списков ниже не предлагать снова без нового довода.

## Версия

- Сайт: **2.97** (10.11.2026). Проверка: `curl -s https://cryptoscreener-topaz.vercel.app/ | grep -m1 -o "v:'[0-9.]*'"`. Если в снимке версия старше — снимок устарел.
- Функции `bot` v52, `tg` v19 и `auth` v5 (2.90; прогоны после выкладки без новых ошибок — только известное «коллектор: no rows») выкладываются из репозитория (GitHub Actions, Supabase CLI закреплён на 2.122.0) и совпадают с ним.

- База: применены миграции из `supabase/*.sql`, последние — `2026-11-signal-books.sql` (09.11, 2.90, стакан в моменты сигналов) и `2026-11-cleanup.sql` (09.11, распутывание аккаунтов, исправление 10). Функции: `bot`, `tg`, `auth` (вход через Telegram).

**Код и сервер:**
- `/scan` закрыт токеном.

**2.56 (плавность графика, `PLAN-MOTION.md`):**

- «Бета»: шкала цены колесом пропорционально, связанные графики получают дробный вид, «к последней свече» возвращает все связанные графики;
