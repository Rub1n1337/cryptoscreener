## Что изменено
- `bot_state.settings`: `tf 1h → 4h`, `strategy revert → switch`, `regimeOnly flat → any` (остальное без изменений).
  Откат: `update bot_state set settings = settings || '{"tf":"1h","strategy":"revert","regimeOnly":"flat"}' where id = 1;`
- Сайт: рекомендуемый профиль «Переключатель · 4h (проверен за год)», сканер и бэктест по умолчанию на 4h.

Ограничение: пары берутся из сегодняшнего топа по объёму; прошлое не гарантирует будущего. Через 1–2 месяца сверить
журнал общего бота с этими цифрами.

### Довод «2024–25 слился, потому что там началась медвежка»
Цены говорят обратное. 2024–25 (где v.6 проиграл): BTC +59% (68k → 107k), ETH +50%, SOL +18%, монеты списка из чата в медиане +25%. 2025–26 (где v.6 дал $228k): BTC −24% (109k → 82k, дно 63k), ETH −40%, SOL −45%, монеты списка в медиане −41%, выросли 2 из 21. Медвежий год — тот, под который профиль подобран.

Список из чата, v.6, 2 позиции:

| | 2025–26 | 2024–25 |
|---|---|---|
| итог с $10 000 | $228 565 | $1 631 |
| шорты | 34 сд, +1.11R (+37.8R) | 28 сд, −0.83R (−23.4R) |
| лонги | 44 сд, +0.77R | 43 сд, −0.17R |
| время в «боковике» по правилам переключателя | 77% | 72% |
| сделки в «боковике» | 58 сд, +0.93R | 57 сд, −0.69R |

Половина прибыли 2025–26 — шорты от верхней границы на падающем рынке; на растущем те же шорты проигрывают. Переключатель видел оба года одинаково (около трёх четвертей времени — «боковик»), то есть заранее отличить «свой» год от «чужого» бот не мог: он торговал бы 2024–25 точно так же. Профиль v.6 — ставка на то, что рынок продолжит падать или пилить, а не правила, которые работают в разных условиях.

Честная проверка без бэктеста и без ИИ — вперёд: список из чата на сервере 24/7 (бумажно) рядом с тем же профилем на «топ-20 на каждый момент», сравнить через 1–3 месяца.
