## Что изменено
- `bot_state.settings`: `tf 1h → 4h`, `strategy revert → switch`, `regimeOnly flat → any` (остальное без изменений).
  Откат: `update bot_state set settings = settings || '{"tf":"1h","strategy":"revert","regimeOnly":"flat"}' where id = 1;`
- Сайт: рекомендуемый профиль «Переключатель · 4h (проверен за год)», сканер и бэктест по умолчанию на 4h.

Ограничение: пары берутся из сегодняшнего топа по объёму; прошлое не гарантирует будущего. Через 1–2 месяца сверить
журнал общего бота с этими цифрами.
