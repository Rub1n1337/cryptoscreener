# План: дизайн по версиям Lovable (с 02.11.2026)

Владелец сделал в Lovable три версии сайта (репозиторий `Rub1n1337/modern-crypto-screener`, код его). Задача: взять лучшие решения и мелкие детали, перенести к нам — без React/Tailwind, на наших токенах (`:root` тёмная, `:root[data-theme=light]` светлая; canvas читает их через `pal()` в `PC`).

Это задел для **v4 (новая дизайн-система)** из `PLAN-V3.md`: значения токенов и отдельные компоненты меняем сейчас, а то, что меняет облик всего сайта (шрифт, скругления, навигация), — решает владелец, и это уходит в v4.

**Статус:** план написан; **волна 1 выложена в 2.60** (02.11.2026). Волны 2–3 не начаты. Следующая сессия начинает с волны 2.

## Где три версии

Одна ветка `main`, одна страница `src/routes/index.tsx` + `src/styles.css`. Версии — состояния истории:

Радиус 12, графит с лёгкой синевой, золотое свечение на фоне |
| **2** | `e53af3f` (29.10, «Упростил и модернизировал UI») | «терминал» на всю высоту: блоки разделены линиями в 1 px, шапка 48 px с номером версии и статусом бота, бегущая строка тикеров, сводка-полоса, скринер слева, подсказка «Как читать», вкладки на телефоне «Скринер / График / Разбор» |

Шрифты во всех трёх: Manrope (текст) и JetBrains Mono (числа). Светлой темы нет ни в одной.

## Решения

| Элемент | Версии 1 / 2 / 3 | У нас (2.59) | Решение |
|---|---|---|---|
| Палитра тёмной темы | 1–2: графит с лёгкой синевой (oklch C .008); 3: нейтральный графит (C .003) | тёмно-синий (C .016–.03) | **Берём 3 — сделано в 2.60.** Светлота наших ступеней почти совпала с 3-й (фон .159/.155, панель .192/.195), поменяли только оттенок: контраст текста тот же или выше (`--faint` 4.8–5.5:1) |
| Акцент, рост, падение | золото, зелёный, красный — по сути наши | `--acc`, `--lo`, `--up` | оставляем |
| Светлая тема | нет | есть, уже нейтральная | оставляем |
| Шрифт | Manrope + JetBrains Mono для чисел | Inter со своего сервера, табличные цифры | **решение владельца, v4.** Новый шрифт — файлы на сервере (CSP: шрифты только свои), вес страницы и проверка всех таблиц на 320 px; цифры Inter уже стоят ровно |
| Скругления | 1–2: 12; 3: 8 | 12 у панелей, 8 у кнопок | **решение владельца, v4.** 8 строже, но меняет облик всего сайта |
| Свечение на фоне | 1–2 золотое пятно сверху; 3 убрал | нет | не берём (3-я сама отказалась) |
| Логотип | золотой квадрат с Σ | свой Σ-канал (полосы и цена) | оставляем свой |
| Название в шапке | 3: «Sigma» жирно, «Radar» приглушённо | «Sigma Radar» жирно | **берём 3 — 2.60** |
| Навигация | 1–2: плашка у выбранной вкладки; 3: золотая черта снизу | плашка | **решение владельца, волна 3** |
| Статус в шапке | 1: «Бот активен» с пульсом; 2: бот, позиции, PnL; 3: «Binance · Live» | пилюля «Общий бот · N поз.», «обновлено N с назад» | оставляем: у нас настоящие данные; бесконечный пульс не «живой» индикатор (§13 п. 54) |

| Сводка | 1: пять карточек с подсказками; 2–3: одна полоса с разделителями | пять карточек с подсказками | **берём 3 + подсказки из 1 — 2.60.** Одна панель, тонкие линии, выбранный фильтр — золотистый фон и черта снизу. Так же — ряды цифр «Журнала» и «Бэктеста» (`.statrow`) |
| Вступление | 1: панель «Понятно»; 2: подсказка с крестиком | «Добро пожаловать» | оставляем; фон — тёплый графит под акцент (2.60) |
| Выбранная строка | 1: черта слева; 3: золотистый фон + черта | синий фон + золотая черта | **берём 3 — 2.60** (как в светлой теме) |
| Аватар монеты | 1–2: цвет по названию в oklch; 3: иконки с CDN | цвет по названию в hsl | **берём 1–2 — 2.60**: все оттенки одной яркости. Иконки с CDN — нет: чужой сервер, CSP |
| Шапка графика | 3: подписанные пары «Макс / Мин / Объём / Диапазон» | строка через точки | **берём 3 — 2.60**: Диапазон, Границы, RSI, T½, Канал |

| График | 3: тонкая сетка, золотая метка цены, развернуть, ±2σ | то же есть (метка, широкий режим, настройки канала) | цвета сетки и осей нейтральные (2.60) |
| Подвал с оговоркой | 3 | есть (`.sfoot`) | есть |
| Кольцо фокуса | 3: золотое | синее | оставляем: золото у нас значит «выбрано» |
| Нижняя панель телефона | 3: золотая черта над выбранной вкладкой | плашка | вместе с навигацией (волна 3) |

## Волны

1. **Токены и самые заметные компоненты — 2.60, выложено.** Графит, сводка-полоса (рынок, журнал, бэктест), выбранная строка, аватары, название в шапке, подписанные цифры в шапке графика.
2. **Таблица и разбор.** ↕ при наведении на сортируемый столбец; одна шкала диапазона (градиент, точка с обводкой); шкала RSI с метками 30 / 70 в «Разборе сигнала». Проверить пустые состояния таблицы и избранного.
3. **Решения владельца (v4).** Подчёркнутая навигация и нижняя панель с чертой; сплошное золото у выбранного фильтра; скругления 8; шрифт Manrope + JetBrains Mono. Делать только после «да» владельца, одним заходом — это облик всего сайта.

## Как проверять

Каждая волна: smoke `await (await import('/tests/smoke.js?' + Date.now())).run()` на 320 / 375 / десктопе в обеих темах, `read_console_messages`, чек-лист §12 `DESIGN-RULES.md`. Контраст новых цветов считать (формула WCAG), а не на глаз.
