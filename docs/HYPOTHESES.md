# Что стоит проверить — список гипотез (16 ноября 2026)

Все идеи торговли, которые ещё не проверены. Они собраны из литературы (`docs/LITERATURE.md`), присланных владельцем
материалов (статьи, слайды, книга о рыночном профиле) и выводов наших прогонов.

Что уже проверено и не прошло, записано в `docs/ATTEMPTS.md`. Повторять это не нужно: список — в конце файла.

**Порядок перед каждой проверкой** (`CLAUDE.md`):

1. Поиск литературы, 1–3 работы в `LITERATURE.md`.
2. Правила записываются до прогона.
3. Каждое сочетание вносится в реестр `ATTEMPTS.md`.
4. Скачивание новых данных — только по «да» владельца.

Прогон — по решению владельца.

**Колонки:**

- «Опора» — насколько гипотезу поддерживает литература: сильная, средняя, слабая, нет.
- «Цена» — сколько стоит проверка: S — данные уже есть, до дня работы; M — 1–3 дня или нужно скачать данные; L — нужно
  копить данные месяцами.

## 5. Не для нас

- **Опционы**: плотность из цен опционов (Breeden–Litzenberger), «греки», поверхности волатильности — нужны данные опционов
  (Deribit), а сайт работает со спотом.
- **Модели Хоукса для новостей** — нужна лента новостей с точным временем.
- **Арбитраж рынков предсказаний** (Polymarket, Kalshi) — другой рынок.
- **Новые модели-прогнозисты** вроде Kronos — независимые проверки на финансах отрицательны, наш прогон тоже.
