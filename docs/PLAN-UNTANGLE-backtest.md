# Бэктест: раскладка по категориям и учебные стратегии (план, 11.11.2026)

Задача владельца: страница «Бэктест» должна читаться по категориям, и в ней — отдельная категория **учебных стратегий**
(Фибоначчи и SMC), которые на нашей истории проигрывают: пользователь запускает их сам и видит результат рядом со
сравнением со случайным входом (2.104). Учебные — только в бэктесте: не в профилях, не в `botTick`, не в общем боте;
`botTick`, `checkExit`, `planEntry` и `fingerprint()` не меняются.

Статус (11.11): **2.105** — раскладка по разделам, **2.106** — учебные стратегии (Фибоначчи, SMC: ордер-блок, SMC: FVG), обе выложены; подробности — `docs/AUDIT-STATE.md`.
Осталось на решение владельца: ранжирование топа с новыми монетами (`AUDIT-STATE.md`, «Открыто»). Предложения: абзац об учебных стратегиях в справке («Бэктест: почему это должно приносить деньги»); исследование FVG по образцу `research/fib.js`, чтобы подсказка могла сказать, проигрывает ли он.

## 0. Решения владельца (11.11)

- Раскладка — **А** (шесть категорий формы, панель «Можно ли верить»).
- SMC, FVG и Фибоначчи — **«чтобы самому можно было настраивать»**. Значит:
  - **Фибоначчи:** порог импульса k × ATR (2 / 3 / 4 / 5, по умолчанию 3), зона отката (0.382–0.5 / **0.5–0.618** / 0.618–0.705), стоп (**0.786** / 0.886 / 1 — начало импульса), цель (**вершина** / расширение 1.272).
  - **SMC: ордер-блок:** как входить — «отскок от границы, если у неё блок своей стороны» (**по умолчанию**, проверено) или «вход при возврате цены в блок» (стоп за блоком, тейк — RR из «Выхода»); длина свинга (5 / **10** / 20 свечей).
  - **SMC: FVG** — третьей учебной идеей сразу: мин. размер разрыва (0 / **0.5** / 1 × ATR), сколько свечей разрыв ждёт возврата (24 / **48** / 96), стоп за дальним краем разрыва, тейк — RR из «Выхода». Не исследовался: подсказка не говорит «проигрывает», а говорит «не проверялась — посмотрите на сравнение со случайным входом».
  - Подсказка «на нашей истории проигрывает» у Фибоначчи и SMC — только про настройки по умолчанию (их проверяли исследования).
- Прочее — по рекомендации: случайный вход для учебных берёт стоп и тейк : стоп из случайной сделки самой стратегии; два выпуска: **2.105** — раскладка, **2.106** — учебные стратегии.

## 2. Что непонятно новичку

1. **Выход разнесён в два места:** RR — в «Риск-менеджменте», тайм-стоп — в «Дополнительно». Это одна вещь: «когда закрываем».
2. **Идея входа без своих параметров:** канал (модель, N, k) определяет саму идею «Отскок / Пробой», а спрятан среди фильтров.
3. **«Дополнительно» — пять разных вещей:** фильтры входа (сила, T½, ширина, тренд монеты, только LONG), фильтр рынка (режим, по чему, ER), параметры идеи (канал), выход (тайм-стоп) и действия (сохранить профиль, очистить кэш).
4. **«Отложить для проверки» стоит рядом с «Запустить»,** хотя это только вид результата (`btParts`, без нового прогона) и относится к «можно ли верить».
5. **«Можно ли верить» рассыпано по странице:** вердикт и случайный вход — наверху, подбор / проверка — в конце второй таблицы, «не загрузились монеты» — в строке состояния, ограничения — сноской под сделками.
6. **Два набора быстрого старта с разным составом:** на пустом экране «общий бот / мой профиль», у кнопки «Запустить» — «общий бот / настройки „Рынка“».
7. **Строка состояния — три смысла:** прогресс, сводка настроек, предупреждения о неполном итоге.
8. **Таблица «По силе сигнала»** не имеет смысла для идеи без силы сигнала (Фибоначчи).

## 3. Скрытые связи, которые затронет задача

- `M.STRATEGIES` (`math.js:309`) — список, по которому **проверяются профили**: `cleanProfile` (`index.html:3384`) и бот (`supabase/functions/bot/index.ts:347`, `oneOf(s.strategy, Object.keys(M.STRATEGIES))`). Учебные стратегии в него класть нельзя — иначе они станут допустимыми в профиле и у сервера. Отдельный список `M.STUDY` рядом.
- `M.STRATEGIES[s.strategy]` читают строка состояния (`4385`), подпись профиля (`2882`) и имя при сохранении (`5128`) — нужен общий `stratName(s)`, знающий оба списка.
- «Сохранить как профиль бота» (`5123`) и «Проверить в бэктесте» из профиля (`btFromProf`) — для учебной идеи первое выключается с подсказкой, второе её не встретит (в профиле её нет).
- `backtest()` (`math.js:510`) решает о входе через `touchedAt` → `signalAt` → `wants` → `planEntry`, а `planEntry` ставит стоп 1.5 ATR. У Фибоначчи свой стоп (0.786) и своя цель (вершина импульса): нужен отдельный путь входа **внутри `backtest()`** — `planEntry` и `botTick` не трогаются. `fingerprint()` `backtest()` не вызывает — отпечаток не изменится.
- `randomSetup` (`math.js:584`) берёт стоп 1.5 ATR. Для Фибоначчи (стоп по уровню, обычно другого размера) «те же выходы» были бы неправдой — см. решение 5.
- Карточка сделки (`showTrade`) и `snapshot` рассчитаны на канал (z, сила, границы). Для учебной сделки — короткий снимок: идея, уровни импульса / блока, настройки.

## 4. Предлагаемая раскладка

### Форма

1. **Что проверяем** — «Идея входа» с двумя группами в списке (`<optgroup>`):
   - «Рабочие стратегии»: Отскок от границы, Отскок по тренду, Пробой границы, Переключатель по режиму рынка;
   - «Учебные — проверить популярные идеи»: Откат по Фибоначчи, Ордер-блок SMC.
   Под списком одна строка подсказки по выбранной идее. Для учебной: «Популярная идея. На нашей истории за несколько лет она проигрывает — запустите, чтобы увидеть, как выглядит стратегия без преимущества и что показывает сравнение со случайным входом.» (без чисел — правило 10 `LESSONS.md`).
   Рядом — параметры идеи: для канальных — Модель / N / k; для Фибоначчи — порог импульса k × ATR (3 по умолчанию; 2 — как проверка в исследовании).
2. **На чём** — Монеты · Топ считать · Свои монеты · Таймфрейм · Период · С / По.
3. **Деньги и риск** — Депозит · Риск на сделку · сложный процент · Плечо до · Позиций.
4. **Выход** — Тейк (RR) · Тайм-стоп. Для Фибоначчи RR скрыт, вместо него текст «стоп 0.786, цель — вершина импульса».
5. **Фильтры входа** (свёрнуто, как сейчас «Дополнительно») — Мин. сила · T½ · Мин. ширина · Тренд монеты · только LONG · Режим рынка · Режим по · Флэт, если ER. Фильтры, которые к выбранной идее не применимы, скрываются (для Фибоначчи остаются режим рынка и только LONG).
6. **Ряд кнопок:** «Запустить» · «Подставить: правила общего бота / мой профиль / настройки „Рынка“» (один набор, тот же на пустом экране) · «Сохранить как профиль бота» (для учебной идеи выключена с подсказкой «учебные стратегии бот не торгует»). «Очистить кэш истории» — к сноске об истории внизу.

### Результат

1. **Итог** — как сейчас: баланс, кривая, карточки.
2. **Можно ли верить** — одна панель: вердикт; строка случайного входа; «Отложить для проверки» (переезжает сюда — меняет только вид) с подбором / проверкой рядом; замечания «сегодняшний топ», «свой список», «не загрузились монеты», «история только с Binance»; для учебной идеи — строка «Учебная стратегия: бот по ней не торгует».
3. **Разбор** — таблицы (без «По силе сигнала», если у идеи нет силы) и сделки; ограничения — сноской в конце, рядом «Очистить кэш истории».

Строка состояния остаётся только для прогресса и сводки «Готово: …».

## 5. Учебные стратегии — правила

### Откат по Фибоначчи (`research/fib.js`, `docs/RESEARCH-2026-10.md` 29.10)

- Импульс — свинг ZigZag с порогом k × ATR(14) на баре (k = 3). Вершина известна по закрытию свечи, на которой цена ушла от неё на порог. Импульс вверх — свинг-минимум, затем свинг-максимум.
- Вход — с бара, когда импульс известен, по закрытию первой свечи, задевшей зону 0.5–0.618 (+ проскальзывание). После импульса вверх — лонг, вниз — шорт. Одно событие на импульс. Сделки нет, если цена раньше (или в той же свече) дошла до 0.786, ушла за вершину или подтвердился следующий свинг.
- Выход — стоп 0.786, цель — вершина импульса (лимит, без проскальзывания); стоп и цель в одной свече — стоп; тайм-стоп и издержки — движка (`S.timeStop`, `closeTrade`).
- Отличия от исследования, которые даёт движок: слоты, пауза по монете (`COOLDOWN`), размер по риску и плечу. Поэтому R на сделку сверяется с исследованием по знаку и порядку (там −0.16…−0.17R на 1h), а не до сотых.

### Ордер-блок SMC (`research/smc_check.js`, `docs/RESEARCH-SMC.md`)

- Свинги — экстремум 10 свечей в обе стороны, известен через 10 свечей; слом структуры — закрытие за последним свингом против тренда; блок — крайняя свеча перед сломом. **Блок существует с бара слома** (`made`), а не с исходной свечи — ошибка первого раунда.
- Блок своей стороны (LONG-блок только для лонга), жив до закрытия за его границей.

### FVG

Правило без заглядывания записать можно: разрыв между максимумом свечи i−2 и минимумом свечи i известен по закрытию свечи i. Но честно его никто не проверял — подсказку «на нашей истории проигрывает» к нему написать нельзя. Предложение: сначала прогон исследования (как `fib.js`), потом решать.

### Движок

- `M.STUDY = {fib: 'Откат по Фибоначчи', smc_ob: 'Ордер-блок SMC'}` рядом со `STRATEGIES`, `M.isStudy(S)`.
- В `backtest()` для учебной идеи: на монету один раз — список событий «бар, сторона, стоп, цель» (Фибоначчи) или блоков с баром появления (SMC), всё по свечам до бара включительно. В цикле по времени вместо `touchedAt → signalAt → wants → planEntry` — событие этого бара и свой расчёт размера по той же формуле, что `planEntry` (риск от баланса или старта, потолок плеча на слот). Порядок кандидатов одного бара — по обороту (как в топе). Выходы, тайм-стоп, издержки — общий цикл без изменений.
- Прежние стратегии идут по прежнему коду: эталонные прогоны в `tests/math.html` не должны сдвинуться ни на сделку.

## 6. Решает владелец

1. **Раскладка формы и результата.**
   - **А (рекомендую):** как в разделе 4 — шесть категорий формы, панель «Можно ли верить», «Отложить для проверки» переезжает в неё.
   - Б: лёгкая — подписи групп над нынешними рядами, тайм-стоп к RR, «Сохранить» и «Очистить кэш» из «Дополнительно»; остальное на месте.
   - В: шаги или вкладки («1. Идея → 2. Монеты → 3. Деньги → Запустить») — не советую: настройки скрыты, больше нажатий, на скриншоте не видно всего.
2. **SMC — какая сделка.**
   - **а (рекомендую):** «Отскок от границы» + фильтр «у границы есть живой ордер-блок своей стороны» — ровно то, что проверено (честно хуже базы во всех трёх годах); выходы движка.
   - б: свой вход — по возвращению цены в блок, стоп за блоком, тейк 2R. Это новое правило, его никто не проверял; подсказку «проигрывает» без прогона не написать.
3. **FVG:** **в предложения до исследования (рекомендую)** или сразу третьей учебной идеей.
4. **Фибоначчи — цель:** **только вершина импульса (рекомендую:** в исследовании 1.272 ничего не меняет) или выбор «вершина / 1.272».
5. **Случайный вход для учебной идеи:** **стоп и отношение тейк : стоп берутся из случайной сделки самой стратегии (рекомендую:** иначе у Фибоначчи «те же выходы» неправда) — только для учебных, у прежних стратегий сравнение не меняется. Или как сейчас — стоп 1.5 ATR для всех.
6. **Выпуски:** **два (рекомендую):** 2.105 — раскладка (только `index.html`), 2.106 — учебные стратегии (`math.js` + форма). Или одним.
