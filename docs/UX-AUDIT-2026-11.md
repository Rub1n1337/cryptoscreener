# UX-аудит по исследованию владельца (16.11.2026, сайт 2.124)

Источники:
- `ui-ux-crypto-dashboard-master-research.md`, 10 разделов: дашборды, когнитивная нагрузка, тёмная тема, типографика, таблицы, графики, Web3, мобильная версия, микровзаимодействия, сводный промпт.
- Публичный NotebookLM владельца «UI/UX for dashboard»: 48 источников и переписка. Открылся после того, как владелец импортировал куки. В переписке Gemini дважды разбирал скриншоты нашего «Рынка» (15.11), затем отвечал про стекло, скругления и безопасность «vibe code». Его советы проверены по отдельности ниже.

Как проверялось:
- превью с выключенным замком входа (копия `serve.ps1` на 8781, файлы на диске не менялись);
- ширины 1440, 1280, 375 и 320 px, тёмная и светлая темы;
- `tests/smoke.js` на «Рынке», «Журнале», «Бэктесте», «Учёбе», «Справке» и `#legal`: в обеих темах при 320 px нет горизонтального скролла, переполнений, обрезанного текста и мелких целей;
- в коде: токены, CSS кнопок и чипов, окна подтверждения, контраст чипов (расчёт WCAG по вычисленным цветам).

Действующие правила — `docs/DESIGN-RULES.md`. Исследование их не отменяет, а только дополняет.

## Расхождения — что стоит править

Приоритет: **A** — заметно для каждого пользователя, **B** — полезно, **C** — мелочь, можно не делать. Цена: S — до часа, M — полдня, L — больше.

| # | Что | Как сейчас | Что предлагается | Цена | Приор. |
|---|---|---|---|---|---|
| 1 | **«Журнал»: ответ на «как дела у бота» ниже первого экрана** (§1.3) | Над балансом идут предупреждение «нет преимущества», профиль бота, «Бот ждёт» и «Сервер работает». На 375 px баланс начинается на 1074 px при высоте экрана 812, на 1280×800 — на 706 px | Поднять полосу «баланс · за всё время · за 7 дней» сразу под переключатель «Общий бот / Мой бот». Предупреждение остаётся рядом и крупным: правило владельца о пометке не меняется, меняется только порядок. Профиль и «Бот ждёт» — ниже. На телефоне предупреждение можно сократить до одной строки с «подробнее» (это уже открытый пункт «Открыто — решает владелец», разбор 02.11) | S–M | A |
| 2 | **Белый текст на зелёном чипе LONG — контраст 3.3 : 1** (§3.3, WCAG AA 4.5) | `.tag.loc` — белый на `--sig-lo #16a34a`, 11.5 px. Это главный чип сайта: подтверждённый LONG в таблице, в «Добро пожаловать», в журнале. У SHORT (`#c9303d`) 5.3 : 1. Слабые сигналы (`.weak`, прозрачность .55) читаются ещё хуже | `--sig-lo` темнее, `#15803d` (≈ 5 : 1), в обеих темах. Сплошная заливка подтверждённого сигнала остаётся: она отделяет «можно входить» от «касания». Переводить всё в полупрозрачные чипы, как советует Gemini, значит стереть эту разницу | S | A |
| 3 | **Пустая правая колонка под таблицей** (совет Gemini «дисбаланс сетки», проверен) | На компьютере таблица — 660 px с внутренним скроллом. Ниже неё справа пусто, пока читаешь «Разбор сигнала» и «Стены». Чтобы выбрать другую монету, нужно прокручивать вверх | Сделать правую колонку липкой (`position: sticky; top: <высота шапки>; align-self: start`): таблица остаётся под рукой, следующая монета — в один клик. Только на ширинах с двумя колонками | S | B |
| 4 | **Недоступная кнопка выглядит как «загружается»** (§9.1) | `button:disabled{opacity:.5;cursor:wait}`, и наведение подсвечивает её как обычную. «Удалить» у единственного профиля, «Прочитать всё» без новых событий и выключенные кнопки бэктеста показывают песочные часы | `cursor: not-allowed` у `:disabled`, наведение — только `button:not(:disabled):hover`; часы оставить у `.busy`, где идёт запрос | S | B |
| 5 | **Окно «Закрыть позицию?» не говорит, с чем закроется** (§7.1, «чек») | «По текущей цене рынка, с обычной комиссией…» — без суммы | Добавить строку-чек: «≈ +$12.40 (+0.6R) после комиссии, по цене $0.6232». Для «Закрыть все» — сумма по всем. Бумажные деньги, но урок «знай, что фиксируешь» — суть учебного сайта | S | B |
| 6 | Ряд инструментов таблицы переносит кнопку «Обновить сейчас» на отдельную строку | При 1280 px кнопка стоит одна на второй строке, поле поиска сжато до «Поиск». При 1440 px всё помещается | Сжать вкладки или убрать подписи-счётчики на средних ширинах, чтобы ряд помещался в одну строку от ~1100 px | S | C |
| 7 | ✓ / ✗ в «Почему сигнал» — текстовые знаки | Берутся из запасного шрифта, на разных системах разной толщины | Заменить на `#i-check` / `#i-x` из своего SVG-набора. Видимость почти не меняется | S | C |

## Что из исследования и ноутбука не подходит — и почему

| Совет | Почему нет |
|---|---|
| Режимы Basic / Advanced (§7.3) | Уже отклонено («Обзор» / «Терминал» — двойная поддержка интерфейса, `AUDIT-STATE.md`). Роль Basic у нас играют «Добро пожаловать», свёрнутые блоки и «Учёба». Открыт отдельный пункт «Первый экран для новичка с одной кнопкой» |
| Без теней, только слои (§3.2, сводный промпт п. 1) | Стекло с кромкой и мягкой тенью — решение владельца (2.69–2.77). Сам ноутбук для стекла советует то же, что у нас: непрозрачная подложка под цифрами, блик сверху, тонкая светлая кромка |
| Перекрасить фон в #090A0C, карточки в #121418 (Gemini) | Наши `#0c0d0f` / `#131517` отличаются на 1–2 единицы — разницы не видно, а это правка всех токенов |
| Все чипы полупрозрачные (Gemini) | Стёрло бы разницу «подтверждённый разворот / касание», см. п. 2 |
| Одна гарнитура (§4.1) | Manrope для текста и JetBrains Mono для чисел — это и есть табличные цифры из §4.3 (TradingView взял IBM Plex Mono). Второй шрифт работает на §4.3 |
| Трекинг −3 % у цены в карточке монеты (Gemini) | Цена там 20 px — эффект заметен только на крупных числах. У баланса журнала (40 px) он уже стоит |
| Свечение и затемнение графика при наведении (§6.3, Gemini) | Украшение: крестовина и подпись цены уже есть, а лишняя перерисовка canvas на каждое движение мыши |
| Lightweight Charts (§6.2) | Свой canvas с каналом, стаканом, тепловой картой и уровнями; библиотека не умеет половины, а сборки и npm у сайта нет (решение по архитектуре) |
| Градиент цели — прогресс не с 0 % (§2.3) | В «Учёбе» прогресс — число пройденных уроков. Засчитывать непройденное в учебном сервисе нечестно |
| Неприятие потерь в текстах подписки (§2.4) | Платного нет, давить нечем и незачем |
| Web3: адреса, газ, сеть, ERC-4337, passkeys (§7.1–7.2, 7.4) | Кошельков и переводов нет, торговля бумажная. От §7.1 полезен только формат «чека» — п. 5 |
| Сайдбар с иконками (§5.3) | На компьютере верхняя панель с SVG-иконками, на телефоне нижняя; разделов пять — сайдбар занял бы ширину таблицы |
| Мини-визуализация «Стен в стакане» (Gemini) | Когда стены есть, блок уже рисует лесенку цен с суммами вокруг текущей цены. Когда их нет — одна строка. Полная картинка — режим «Стакан» по ссылке из блока |
| Формула скруглений «внутренний = внешний − отступ» (ноутбук) | Где отступ мал (`.seg` 8 px, внутри 3 px), расхождение — 1 px, на глаз не видно. Где отступ больше радиуса, формула даёт 0, и прямые углы внутри карточек смотрятся хуже |
| Безопасность «vibe code» (ноутбук) | Проверено: заголовки против встраивания есть, `.map` нет, цены и права проверяются на сервере (RLS, `ub_*`). Нового не найдено |
| Toast на каждое действие (§10, п. 4) | Тосты уже на действиях, которые что-то меняют. На смену таймфрейма или фильтра тост — шум: результат и так виден |

## Предложения дополнить `DESIGN-RULES.md`

Только то, чего там ещё нет и что ловит реальную ошибку:

1. **§4 (таблицы), новый пункт:** «Первый экран раздела отвечает на его главный вопрос. „Рынок“ — что с рынком, „Журнал“ — сколько у бота сейчас, бэктест — можно ли верить. Пояснения и настройки — ниже ответа, а не над ним». Из п. 1.
2. **§2, к п. 9:** «Текст на сплошной цветной заливке (чипы, кнопки) — не меньше 4.5 : 1. Белый на зелёном проверять отдельно: средний зелёный даёт около 3 : 1». Из п. 2.
3. **§6, новый пункт:** «`disabled` — „нельзя“ (`not-allowed`, без наведения), `.busy` — „идёт запрос“ (спиннер, часы). Не путать». Из п. 4.
4. **§10, к п. 45:** «Окно необратимого действия называет результат числом: сумму, P&L, сколько сделок удалится». Из п. 5.
