# План v3: выход «Беты» (с 28.10.2026)

**Дорожная карта владельца (28.10.2026):**
- **v3** — «Бета» выходит из закрытого доступа и становится частью сайта.
- **v4** — новая дизайн-система. Отдельный план после v3; до него новых компонентов «на будущее» не делать.

**Статус:** план создан, этап 0 не начат. Сайт — 2.54.

Каждый этап — отдельная версия 2.5x, кроме последнего: он и есть 3.0. Порядок выкладки и проверки — как в `PLAN-2026-10-26.md` («Как выкладываем каждый заход») и чеклист §12 `DESIGN-RULES.md`.

## Что такое «Бета» сейчас

- `beta.js` (~1.5k строк), грузится только после входа: пароль владельца (`beta_owner`) или временный код `SR-XXXX-XXXX` (`beta_issue` / `beta_redeem` / `beta_revoke`, таблицы `beta_keys`, `beta_fails`).
- До четырёх графиков сразу, у каждого своя монета, таймфрейм и потоки Binance (спот и фьючерсы USDⓈ-M) прямо из браузера. На сервере ничего не хранится: тепловая карта копится с момента открытия вкладки.
- Индикаторы (`CATS` в `beta.js`):
  - стакан: стакан, дисбаланс, динамика, Σ стакана, тепловая карта, стенки;
  - сделки и объём: лента, пузыри крупных сделок, поток ликвидности, объём, дельта, CVD, футпринт и маркеры кластеров;
  - фьючерсы: ликвидации и их тепловая карта, открытый интерес;
  - профиль и средние: профиль объёма, POC, динамический POC, профиль участка, VWAP;
  - классика: Боллинджер, RSI;
  - рисование: уровни Фибоначчи, канал Раффа, VWAP от свечи.
- Когда открыта «Бета», новая версия сайта не перезагружает вкладку сама, а сначала спрашивает (`LESSONS.md`, «Сайт и интерфейс»).

## Этапы

**0. Разбор «Беты» (без правок кода).** Пройти каждый индикатор и инструмент:
- работает ли он на 320 / 375 px и на десктопе;
- нагрузка при четырёх графиках: CPU, память, число WebSocket;
- что ломается при обрыве потока.

Итог — таблица «оставить в 3.0 / доделать / убрать или оставить экспериментом» и список багов. Показать владельцу и дождаться решения.

**1. Баги и производительность** по итогам этапа 0.

**2. Открытый доступ.**
- Убрать замок и вход по паролю.
- Решить с владельцем, что делать с кодами доступа: удалить `beta_*` из базы или оставить для будущих закрытых проверок. По умолчанию — оставить функции и убрать форму.
- Название вкладки: «Бета» → постоянное имя (предложить 2–3 варианта).

**3. Связь с остальным сайтом.**
- Из карточки монеты на «Рынке» — переход в этот график с той же монетой.
- Стенки в карточке монеты и запись стакана в моменты сигналов: первый пункт из разбора сайта Drex, он же начинает сбор данных для `PLAN-WALLS.md`. Запись в базу — только с согласия владельца на миграцию.

**4. Справка и право.**
- Раздел «Как это работает» для новых инструментов.
- Обновить `#legal`: стаканы и фьючерсные данные Binance, всё, что начнёт храниться на сервере (`LESSONS.md`, строка про `#legal`).

**5. Выпуск 3.0.**
- Запись в «Что нового» по правилам `CLAUDE.md`.
