# Реестр попыток

Здесь собраны все проверенные идеи торговли и все сочетания параметров в каждой проверке. Правило записано в
`CLAUDE.md`, раздел про литературу.

Зачем реестр: чем больше сочетаний перепробовано, тем вероятнее, что лучшее из них в плюсе случайно. Новый «плюс»
оценивается с учётом числа строк выше него.

Колонки:

- «Сочетаний» — сколько вариантов правил прогнано в этой проверке. Для подбора — размер сетки.
- «Честный топ» — монеты из топ-50 по обороту на каждый момент, включая снятые с торгов.
- Итог «нет» значит, что заранее записанный критерий не выполнен.
- Подробности — в документе из колонки «Где».
