# Реестр попыток

Здесь собраны все проверенные идеи торговли и все сочетания параметров в каждой проверке. Правило записано в
`CLAUDE.md`, раздел про литературу.

Зачем реестр: чем больше сочетаний перепробовано, тем вероятнее, что лучшее из них в плюсе случайно. Новый «плюс»
оценивается с учётом числа строк выше него.

Колонки:

- «Сочетаний» — сколько вариантов правил прогнано в этой проверке. Для подбора — размер сетки.
- «Честный топ» — монеты из топ-50 по обороту на каждый момент, включая снятые с торгов.
- Итог «нет» значит, что заранее записанный критерий не выполнен.
- Подробности — в документе из колонки «Где».

## Поправка на перебор: дефлированный коэффициент Шарпа (16.11)

Метод — Bailey и López de Prado (2014), `docs/LITERATURE.md` §1. Функции — `sharpeOf`, `psr`, `expMaxSR`, `dsr` в
`math.js`, проверки — блок 2.127 в `tests/math.html`.

- Шарп здесь считается **на сделку**: средний R, делённый на разброс R.
- **Вероятностный Шарп** (PSR) — вероятность, что настоящий Шарп больше нуля. Учитывает число сделок, асимметрию и толстые
  хвосты.
- **Дефлированный** (DSR) — то же, но против порога: лучшего Шарпа, который при N попытках даёт одно везение. Разброс
  Шарпа между попытками по умолчанию берётся как у одной оценки без преимущества, 1 / (n − 1).

**Какой Шарп на сделку даёт одно везение** — лучшая из N попыток при n сделках в каждой:

| Сделок | 1 попытка | 20 | 100 | 300 |
|---|---|---|---|---|
| 50 | 0 | 0.27 | 0.36 | 0.41 |
| 100 | 0 | 0.19 | 0.25 | 0.29 |
| 200 | 0 | 0.14 | 0.18 | 0.21 |
| 500 | 0 | 0.09 | 0.11 | 0.13 |
| 1000 | 0 | 0.06 | 0.08 | 0.09 |

Для сравнения: у сделки с RR 1 : 2 и средним +0.2R Шарп около 0.14. При наших ~200 попытках такой результат
неотличим от везения, пока сделок меньше ~500.

**Прошлые «плюсы» с этой поправкой.** Оценка приблизительная: сделка взята как −1R или +RR, без толстых хвостов. N —
сколько попыток было сделано к тому дню.

| Результат | Сделок | Шарп | PSR | DSR при N того дня | DSR при N = 300 |
|---|---|---|---|---|---|
| 11.10, переключатель 4h, сегодняшний топ-50, год, +0.18R | 62 | 0.12 | 83 % | 17 % (N = 20) | 3 % |
| 12.10, v.2 1h, RR 1:3, +0.21R | 132 | 0.11 | 90 % | 19 % (N = 40) | 6 % |
| 19.10, сегодняшний топ-50, 2025–26, +0.32R | 30 | 0.22 | 87 % | 12 % (N = 60) | 4 % |
| 20.10, гипотеза Gemini, 1h, 2025–26, +0.22R | 49 | 0.15 | 85 % | 7 % (N = 100) | 3 % |
| 13.10, топ-20 на каждый момент из 50, +0.75R | 82 | 0.51 | 100 % | 99 % (N = 30) | 94 % |

- Первые четыре «плюса» поправка отсекла бы сразу: вероятность, что они не везение, 7–19 %.
- Последний она пропускает, но доверять ему рано. Набор из 50 монет был собран по сегодняшнему списку, без снятых с торгов
  (`PLAN-WALLS.md` §11), и проверен только на одном году. На честном пуле за три года эти настройки отдельно не
  перепроверялись; правила общего бота на таком пуле проиграли все три года (19.10). **Поправка на перебор не ловит
  смещённые данные**: выбор монет задним числом, заглядывание
  вперёд, выжившие монеты. Для этого остаются честный пул, проверка обрезкой и отложенный год.

**Правило для следующих прогонов.** Каждый прогон сообщает DSR своего главного сочетания. N — полное число строк
реестра на день прогона вместе с новыми сочетаниями. «Работает» требует DSR ≥ 95 % в каждом проверочном году, вдобавок к
собственному критерию прогона.
