# Sigma Radar — crypto screener

Сканер спот-рынка Binance (пары к USDT): выход цены за статистический канал, подтверждение разворота объёмом, сжатия волатильности, скорость возврата к среднему (T½) и бумажный торговый бот с журналом.

Сайт — статический `index.html` (ES-модуль) без сборки и зависимостей, плюс `beta.js` (раздел «Бета») и общая математика стратегии `supabase/functions/_shared/math.js`, которую используют и сайт, и серверные боты, и коллектор. Данные — публичный API Binance (`data-api.binance.vision`, запасной `api.binance.com`).

## Модели канала
- **Лог-канал** (по умолчанию) — SMA ± k·σ в ln(цены), полосы = exp(…)
- **Классика** — SMA ± k·σ (Bollinger)
- **Робастная** — медиана ± k·1.4826·MAD (чувствительная: ловит выходы на новый уровень)
- **EWMA** — экспоненциальное среднее ± k·EW-σ (канал шире, лучше k ≈ 2)

Для выбранной монеты под графиком — «Разбор сигнала»: какие условия выполнены и из чего сложилась оценка.

Подробности формул — во вкладке «Справка» на странице.

## Боты
- **Общий бот 24/7** — Supabase Edge Function `supabase/functions/bot`, запускается каждую минуту через `pg_cron` (`supabase/cron.sql`). Пишет в таблицы `bot_state`, `positions`, `trades`; сайт читает их публичным ключом (только чтение, RLS).
- **Мой бот** — те же правила с вашими профилями: в браузере (журнал в localStorage, пока открыта вкладка) или на сервере 24/7 (таблицы `user_bots`, `user_positions`, `user_trades`, доступ по секрету бота из браузера). Вход — по закрытой свече, как в бэктесте; режим рынка (боковик / тренд) — на таймфрейме профиля, граница боковика — своя у профиля или общая.
- **Бэктест** — те же функции из `math.js` на истории Binance: «топ на каждый момент» (по обороту за 24 ч, с монетами, снятыми с биржи за период) или «по сегодняшнему топу» (быстрее, завышает — сайт так и пишет). Комиссия, проскальзывание и проценты за заём под шорт и плечо учитываются.
- **Коллектор** (`server/`, Railway) — держит стаканы, тепловую карту и кластеры для «Беты» и отдаёт серверным ботам свечи и анализы (`POST /scan`, только с токеном: переменная `SCAN_TOKEN` = `bot_secret.scan` из Supabase; без неё маршрут закрыт).

Открытые вкладки сами перезагружаются, когда выходит новая версия сайта.

Каждый прогон общего бота пишется в `bot_runs` (хранится 3 дня) — на сайте это панель «Работа сервера».

### Telegram
Один Telegram-бот на всех. Любой, кто нажал в нём Start, получает сделки общего бота. Владелец «Моего бота» на сервере привязывает к нему свой чат (сайт → Журнал → Мой бот → «Подключить Telegram») и получает:
- сделки своего бота;
- «Мои сигналы» — по правилам своего бота, на его монетах или шире (топ-50…250, для ручной торговли); одно сообщение на касание, оно обновляется при подтверждении разворота и при входе бота; можно присылать только подтверждённые или сразу при касании, только LONG, ночью без звука;
- «Рынок» — отдельный фильтр со своими настройками канала, сохранёнными на сайте кнопкой (сам не меняется, когда переключаешь страницу «Рынок»).

Настройки хранятся в `user_bots.alerts` (`supabase/alerts.sql`), меняются на сайте и в меню бота (/menu, /notify). На команды отвечает функция `tg` сразу (вебхук с `secret_token`); его регистрирует сам бот и раз в 10 минут проверяет — после смены токена ничего настраивать не нужно.

Схема базы целиком — `supabase/schema.sql`, затем `supabase/hardening.sql`; Telegram — `supabase/telegram.sql`. Токен хранится только в закрытой таблице `tg_config` (без публичного доступа). Подключение — токен и имя бота (без @) от @BotFather, затем в SQL Editor:
```sql
update public.tg_config set enabled = true, bot_token = '<ТОКЕН>', bot_name = '<ИМЯ_БОТА>' where id = 1;
```
`chat_id` можно не заполнять (старый способ: ещё один чат, куда идут сделки общего бота).

## Запуск локально
```
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
```
и открыть http://localhost:8765/

## Деплой
Статический сайт — Vercel отдаёт `index.html` из корня без настроек.

> Учебный инструмент. Торговля только бумажная (виртуальный баланс в браузере или в Supabase, реальных ордеров нет), это не инвестиционный совет.
